# Inspection fixtures

`recorded/inspection-report-v2.json` captures the version 2 public library with a fake Sandbox Provider, recorded model replies, release metadata and Patch mailboxes for the example repository. The library produced the timeline, role usage, Verdict and digests. Replay preserves the event intervals. `recorded/inspection.json` is the earlier version 1 capture used to check stored report compatibility. `createTestSite.ts` supplies the credential-free HTTP test app, posts submissions to it and waits for an upgrade menu build. `createUpgradeMenuHarness.ts` serves a hosted site whose source answers every repository with a canned upgrade menu, for the `discoverUpgrades.test.ts` tests of menu builds. `stalledUpgradeMenuProcess.ts` is a build process that never answers, for the time and memory limit tests in `buildUpgradeMenu.test.ts`. Run `bun test apps/web` after changing either recording.
